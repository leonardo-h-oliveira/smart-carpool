# Project context

Smart Carpool and UniCar both deal with carpooling in a university community, but they are not versions of the same application.

## Smart Carpool

Smart Carpool is a web portfolio project developed by Leonardo Henrique Oliveira. It uses FastAPI, SQLAlchemy, PostgreSQL, HTML, CSS and JavaScript. Its scope includes authentication, user profiles, vehicle management, ride publishing, booking requests, privacy rules, automated tests and a public demonstration.

## UniCar

UniCar was an undergraduate final project developed by Leonardo Henrique Oliveira and Bruna Helena Antonialli Gomes at UNIFAL-MG. It was an Android prototype made with MIT App Inventor, Firebase and TinyDB. Its academic report documents the original screens, block-based logic and project limitations.

## What they share

The projects share a problem domain and some basic concepts, such as drivers, passengers, ride offers and seat availability. Smart Carpool was not created by porting the UniCar source code, reproducing its interface or continuing its repository history.

References to UniCar in this repository provide authorship and academic context only. Technical claims about Smart Carpool refer exclusively to the code and tests contained in this repository.
